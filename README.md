# Sprite Breakdown (MVP)

Free, mobile-friendly pixel-art tool. Upload a sprite PNG, get a step-by-step
drawing guide generated by pure static analysis — no AI, no uploads, no accounts.

**Live:** https://zichaelpath.github.io/pixel-art-tools/

## How it works

Everything runs client-side in a single `index.html` (no build step, no dependencies):

- **Exact palette census** — pixel art uses exact colors, so we just count them.
- **Role classification** — outline (hugs transparency), fills, shades/highlights
  (same-hue darker/lighter variants), accents, via honest documented heuristics.
- **Dithering detection** — 2x2 checkerboard pattern scan.
- **Step-by-step guide** — silhouette → fills → shading → highlights → outline →
  details, each rendered as a zoomed pixel grid with the colors added at that step.
- **Palette export** — click-to-copy hex, `.gpl` for Aseprite/LibreSprite.

## Develop

- `src/analysis.js` — pure analysis (no DOM), unit-tested.
- `src/app.js` — app shell.
- `src/style.css`, `src/template.html`
- `python3 build.py` → `dist/index.html`
- `python3 test/run_tests.py` — unit tests via GJS (SpiderMonkey) on a
  PIL-generated sprite with known colors; `gjs /tmp/domtest.js` — app-shell
  integration test with a fake DOM.

## Privacy

Images never leave the device. No server, no analytics, no accounts.
